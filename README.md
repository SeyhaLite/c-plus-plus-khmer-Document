# ឯកសារ C++ ជាភាសាខ្មែរ

គម្រោងនេះបង្កើតឯកសាររៀន និងឯកសារយោងសម្រាប់ភាសា **C++** ជាភាសាខ្មែរ។ ខ្លឹមសាររៀបចំពីមេរៀនមូលដ្ឋាន រហូតដល់ប្រធានបទកម្រិតខ្ពស់ ដោយមានការពន្យល់ ឧទាហរណ៍កូដ និងប្រភពសម្រាប់ស្វែងយល់បន្ថែម។

គេហទំព័រប្រើ **Sphinx**, **MyST Markdown** និងរចនាប័ទ្ម **Furo** ហើយអាចបង្កើត និងបង្ហោះតាម **Read the Docs**។

## គោលដៅរបស់គម្រោង

- ជួយអ្នករៀន C++ តាមលំដាប់ពីងាយទៅពិបាក។

- ភ្ជាប់ប្រភពយោងដែលអាចផ្ទៀងផ្ទាត់បាន។
- ពិនិត្យគុណភាពឯកសារ និងសាកល្បងឧទាហរណ៍កូដដោយស្វ័យប្រវត្តិ។

## លក្ខណៈពិសេស

- **ការស្វែងរកភាសាខ្មែរ៖** ប្រើការបំបែកពាក្យស្វែងរកជាពីរតួអក្សរត្រួតគ្នា ដើម្បីជួយស្វែងរកអត្ថបទខ្មែរដែលមិនសូវមានចន្លោះរវាងពាក្យ។
- **ជ្រើសរើសស្តង់ដារ C++៖** អាចជ្រើសស្តង់ដារដូចជា C++11, C++17, C++20 និង C++23 ដើម្បីជួយកំណត់ប្រធានបទតាមសមត្ថភាពរបស់ Compiler។
- **ស្លាកស្ថានភាពមេរៀន៖** បង្ហាញស្ថានភាពបកប្រែ ស្តង់ដារអប្បបរមា និងប្រភពយោងរបស់ទំព័រ។
- **បញ្ជីពាក្យបច្ចេកទេស៖** រក្សាការប្រើពាក្យខ្មែរឱ្យមានភាពស៊ីសង្វាក់គ្នា។
- **តារាងវឌ្ឍនភាព៖** គណនាចំនួនទំព័រ និងស្ថានភាពពីឯកសារពិត។
- **ឧទាហរណ៍ C++៖** មានស្គ្រីបសម្រាប់ Compile, Run និងប្រៀបធៀបលទ្ធផលជាមួយលទ្ធផលរំពឹងទុក។
- **រចនាប័ទ្មគេហទំព័រ៖** គាំទ្ររបៀបពន្លឺ និងងងឹត ព្រមទាំងការបង្ហាញលើអេក្រង់ទំហំផ្សេងៗ។

## តម្រូវការមុនពេលចាប់ផ្ដើម

- Python **3.12**
- C++ Compiler ដូចជា **GCC** ឬ **Clang** (ត្រូវការសម្រាប់តេស្តឧទាហរណ៍កូដ)
- Git

## ដំឡើង និងបង្កើតគេហទំព័រនៅលើម៉ាស៊ីនផ្ទាល់ខ្លួន

### 1. ទាញយក Repository

```bash
git clone https://github.com/SeyhaLite/c-plus-plus-khmer-Document.git
cd c-plus-plus-khmer-Document
```

### 2. បង្កើត Python virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

នៅលើ Windows អាចប្រើ៖

```powershell
.venv\Scripts\Activate.ps1
```

### 3. ដំឡើង Packages

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. បង្កើតឯកសារ HTML

```bash
make html
```

ឯកសារដែលបានបង្កើតនឹងស្ថិតនៅ៖

```text
docs/_build/html/
```

### 5. បើកមើលគេហទំព័រនៅក្នុងម៉ាស៊ីនផ្ទាល់ខ្លួន

```bash
make serve
```

បន្ទាប់មកបើក [http://localhost:8000](http://localhost:8000) ក្នុង Browser។

### 6. ដំណើរការតេស្តទាំងមូល

```bash
make check
```

ពាក្យបញ្ជានេះដំណើរការការផ្ទៀងផ្ទាត់ខ្លឹមសារ ការតេស្តឧទាហរណ៍ C++ និងការបង្កើត Sphinx HTML ដោយចាត់ទុក Warning ជាកំហុស។

## ពាក្យបញ្ជាសំខាន់ៗរបស់ Pipeline

Pipeline ស្ថិតនៅក្នុង `scripts/pipeline.py`។

| ពាក្យបញ្ជា | គោលបំណង |
| --- | --- |
| `python scripts/pipeline.py status` | បង្ហាញស្ថិតិវឌ្ឍនភាព |
| `python scripts/pipeline.py status --write` | គណនាស្ថិតិ និងរក្សាទុកក្នុង `data/progress.json` |
| `python scripts/pipeline.py validate --strict` | ផ្ទៀងផ្ទាត់ឯកសារទាំងអស់ និងបរាជ័យបើមាន Error |
| `python scripts/check_examples.py --strict` | Compile និង Run ឧទាហរណ៍ C++ ទាំងអស់ |
| `python scripts/pipeline.py discover` | ពិនិត្យប្រភពយោងតាមបណ្តាញអ៊ីនធឺណិត |
| `python scripts/pipeline.py fetch --page basics/variables` | ទាញយកអត្ថបទប្រភពសម្រាប់ទំព័រមួយ |
| `python scripts/pipeline.py verify --page basics/variables` | ពិនិត្យទំព័រមួយ |
| `python scripts/pipeline.py verify --page basics/variables --accept` | ទទួលស្គាល់លទ្ធផលផ្ទៀងផ្ទាត់ បន្ទាប់ពីការត្រួតពិនិត្យជោគជ័យ |

### ការប្រើ API សម្រាប់ជំនួយបកប្រែ

Pipeline អាចប្រើ OpenAI API ដើម្បីបង្កើតសេចក្ដីព្រាងបកប្រែ។ ពាក្យបញ្ជាឧទាហរណ៍៖

```bash
python scripts/pipeline.py translate --page basics/my-topic --provider openai
```

មុនបកប្រែទំព័រថ្មី ត្រូវបន្ថែមទំព័រ និងប្រភពយោងរបស់វាទៅក្នុង `data/inventory.json` ជាមុនសិន។ បន្ទាប់មកទាញយកអត្ថបទប្រភព និងបង្កើតសេចក្ដីព្រាង៖

```bash
python scripts/pipeline.py fetch --page basics/my-topic
python scripts/pipeline.py translate --page basics/my-topic --provider openai
```

ពាក្យបញ្ជាខាងលើជាគំរូ។ ត្រូវប្រើ Page ID ដែលមានក្នុង Inventory ពិតប្រាកដ។ Pipeline មិនសរសេរជាន់លើឯកសារដែលមានអត្ថបទរួចទេ លុះត្រាតែប្រើជម្រើស `--force`។

កំណត់ API key តាមអថេរបរិស្ថាន៖

- `KHMER_TRANSLATE_API_KEY`
- ឬ `OPENAI_API_KEY`

Endpoint លំនាំដើមគឺ `https://api.openai.com/v1`។ អាចកំណត់ `KHMER_TRANSLATE_BASE_URL` ដើម្បីប្រើសេវា OpenAI-compatible ផ្សេងទៀតបាន ប៉ុន្តែត្រូវប្រើតែសេវាដែលអ្នកទុកចិត្ត ព្រោះ API key និងអត្ថបទប្រភពនឹងត្រូវផ្ញើទៅ Endpoint នោះ។ **កុំដាក់ API key ក្នុងកូដ ឯកសារ README ឬ Git Commit។**

អត្ថបទដែលបង្កើតដោយស្វ័យប្រវត្តិត្រូវចាត់ទុកជាសេចក្ដីព្រាង។ ត្រូវពិនិត្យខ្លឹមសារ និងដំណើរការ Validation មុនពេលទទួលស្គាល់ថាបានផ្ទៀងផ្ទាត់។

ស្ថានភាព `verified` បញ្ជាក់ថាបានឆ្លងកាត់លក្ខខណ្ឌបច្ចេកទេសរបស់គម្រោង។ វាមិនមានន័យថាអ្នកជំនាញភាសាខ្មែរឯករាជ្យបានកែសម្រួល និងអនុម័តគ្រប់ប្រយោគរួចហើយទេ។

## ការដាក់ឱ្យដំណើរការលើ Read the Docs
