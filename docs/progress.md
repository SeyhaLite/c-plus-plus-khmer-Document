# វឌ្ឍនភាពបកប្រែ

ទំព័រនេះបង្ហាញស្ថិតិពិតប្រាកដរបស់គម្រោង។ លេខទាំងអស់ត្រូវបានគណនាដោយស្វ័យប្រវត្តិ
ពីឯកសារ `data/inventory.json` និងពីឯកសារពិតនៅលើដីស្គ្រីប នៅពេលបង្កើតគេហទំព័រ។
គ្មានលេខណាមួយត្រូវបានសរសេរដោយដៃឡើយ។

## របៀបគណនា

```text
ភាគរយសម្រេច = (ទំព័របកប្រែរួចដែលមានឯកសារពិត / ទំព័រត្រូវការសរុប) × 100
```

ទំព័រមួយត្រូវរាប់ថា «បានបកប្រែ» លុះត្រាតែ៖

1. វាមានឯកសារ Markdown ពិតនៅក្នុង `docs/`។
2. ឯកសារនោះជា UTF-8 ត្រឹមត្រូវ និងមានអក្សរខ្មែរយ៉ាងតិច 400 តួ។
3. វាមាន directive `translation-meta` ត្រូវនឹង id របស់ខ្លួន។
4. វាមានប្រភពយោងយ៉ាងតិចមួយ។

បើស្ថានភាពក្នុងបញ្ជីនិយាយថា «បានបកប្រែ» ប៉ុន្តែឯកសារបាត់ ឬខ្លីពេក
ទំព័រនោះត្រូវរាប់ជា «បរាជ័យ» មិនមែនជាវឌ្ឍនភាពឡើយ។

## អ្វីដែលនៅសល់

ទំព័រដែលនៅសល់ត្រូវបានរាយនៅក្នុងផ្នែក «ទំព័រដែលនៅសល់» ខាងលើ។
គម្រោងនេះធ្វើការបន្ថែមម្ដងមួយក្រុម៖ បកប្រែ → ផ្ទៀងផ្ទាត់ → បង្ហាញលទ្ធផល។
យើងមិនបង្កើតទំព័ររាប់ពាន់ដោយគុណភាពទាបដើម្បីធ្វើឱ្យលេខឡើងខ្ពស់ឡើយ។
