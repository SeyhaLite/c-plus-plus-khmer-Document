# បណ្ណាល័យស្តង់ដារ

បណ្ណាល័យស្តង់ដារ C++ ផ្ដល់ធុងទិន្នន័យ អាល់ហ្គោរីត ខ្សែអក្សរ ការបញ្ចូល/បញ្ចេញ
និងឧបករណ៍ជាច្រើនទៀត។ ការប្រើវាឱ្យបានល្អគឺជាផ្នែកសំខាន់នៃការសរសេរ C++ ទំនើប។

## ចំណុចសំខាន់ដែលនឹងមកដល់

- **ធុងទិន្នន័យ** — `std::vector`, `std::map`, `std::unordered_map`, និងការជ្រើសរើសត្រឹមត្រូវ។
- **អាល់ហ្គោរីត** — `std::sort`, `std::find`, `std::transform`។
- **អ្នកដើរកាត់** — ភ្ជាប់ធុងទិន្នន័យជាមួយអាល់ហ្គោរីត។
- **ខ្សែអក្សរ** — `std::string`, `std::string_view`។
- **ឯកសារ និងពេលវេលា** — `std::filesystem` (C++17), `std::chrono` (C++11)។
- **Ranges** — បណ្ណាល័យថ្មីក្នុង C++20។
