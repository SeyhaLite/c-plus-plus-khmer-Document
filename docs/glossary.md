# បញ្ជីពាក្យបច្ចេកទេស

ដើម្បីឱ្យឯកសារទាំងមូលមានភាពស៊ីសង្វាក់ យើងប្រើពាក្យខ្មែរតែមួយសម្រាប់គំនិតតែមួយ។
តារាងខាងក្រោមត្រូវបានបង្កើតដោយស្វ័យប្រវត្តិពី `data/terminology.json`
ដែលជាឯកសារតែមួយគត់ដែលកំណត់ពាក្យផ្លូវការ។

## គោលការណ៍បកប្រែ

1. រក្សាពាក្យគន្លឹះ C++ ដើមដូចជា `int`, `double`, `nullptr` ដោយមិនបកប្រែ។
2. ដាក់ពាក្យបច្ចេកទេសអង់គ្លេសក្នុងវង់ក្រចកនៅពេលលើកដំបូង ដូចជា
   អថេរ (Variable)។
3. សរសេរខ្មែរឱ្យអានដឹង មិនបកប្រែតាមពាក្យម្ដងមួយៗ។
4. រក្សាកូដ និងវាក្យសម្ព័ន្ធដើមទាំងស្រុង។
5. បើពាក្យណាមួយមិនទាន់មានក្នុងបញ្ជី សូមបន្ថែមវាទៅ `data/terminology.json`
   មុននឹងប្រើ ដើម្បីកុំឱ្យពាក្យប្លែកគ្នារវាងទំព័រ។
