# ម៉ូឌុល (Modules)

```{translation-meta} advanced/modules
```

ម៉ូឌុល (module) ជាលក្ខណៈ **C++20** ដែលជំនួសព្រៃដំណើរការ `#include` សម្រាប់ការរៀបចំកូដ។
ជំនួសឱ្យការចម្លងឯកសារក្បាលទាំងស្រុង ម៉ូឌុលបង្កើតឯកតាដែលបានបកប្រែរួច
ហើយនាំចូលដោយ `import`។

## ឯកតាប្រទាក់ម៉ូឌុល

```cpp
// math.cppm — ឯកតាប្រទាក់ (module interface unit)
export module math;

export int add(int a, int b) {
    return a + b;
}
```

`export module math;` ប្រកាសឈ្មោះម៉ូឌុល។ `export` នៅមុខអនុគមន៍ធ្វើឱ្យវាអាចមើលឃើញ
ពីខាងក្រៅ។ អ្វីដែលមិន `export` គឺជាកូដខាងក្នុងម៉ូឌុល។

## ការនាំចូល

```cpp
import math;
#include <iostream>

int main() {
    std::cout << add(2, 3) << '\n';
}
```

## អត្ថប្រយោជន៍

- **ល្បឿនបកប្រែ** — ម៉ូឌុលមិនត្រូវវិភាគឯកសារក្បាលឡើងវិញរាល់ឯកសារ។
- **គ្មានការលេចធ្លាយម៉ាក្រូ** — `#define` ក្នុងម៉ូឌុលមិនប៉ះពាល់អ្នកនាំចូល។
- **ការញែកដាច់ច្បាស់** — អ្វីដែលផ្ដល់ឱ្យគឺច្បាស់លាស់ជាងឯកសារក្បាល។

## ការគាំទ្ររបស់កម្មវិធីបកប្រែ

| កម្មវិធីបកប្រែ | ស្ថានភាព |
| --- | --- |
| MSVC | គាំទ្រម៉ូឌុល (ប្រើឯកសារ `.ixx`) |
| Clang | គាំទ្រមួយផ្នែក (ត្រូវការការកំណត់បន្ថែម) |
| GCC | គាំទ្របែបពិសោធន៍ ត្រូវប្រើ `-fmodules-ts` |

:::{warning}
**ឧទាហរណ៍ក្នុងទំព័រនេះមិនត្រូវបានបកប្រែដោយស្វ័យប្រវត្តិទេ។**
គម្រោងនេះសាកល្បងគំរូកូដទាំងអស់ដោយ `g++ -std=c++NN`។ ការគាំទ្រម៉ូឌុលរបស់ GCC 13
នៅជាបែបពិសោធន៍ ហើយត្រូវការ `-fmodules-ts` ដូច្នេះយើងមិនដាក់វាក្នុង
បញ្ជីគំរូដែលបានផ្ទៀងផ្ទាត់ឡើយ។ កូដខាងលើគោរពតាមវាក្យសម្ព័ន្ធស្តង់ដារ
(សូមផ្ទៀងផ្ទាត់ជាមួយកម្មវិធីបកប្រែរបស់អ្នក)។
:::

## ការបកប្រែដោយដៃ (GCC)

```bash
g++ -std=c++20 -fmodules-ts -c math.cppm -o math.o
g++ -std=c++20 -fmodules-ts main.cpp math.o -o app
```

លំដាប់ និងជម្រើសអាចខុសគ្នាតាមកំណែកម្មវិធីបកប្រែ។ សូមអានឯកសារផ្លូវការរបស់វា។
