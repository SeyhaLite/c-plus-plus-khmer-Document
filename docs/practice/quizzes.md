# សំណួរសាកល្បង

```{translation-meta} practice/quizzes
```

សំណួរសាកល្បងជួយឱ្យអ្នកពិនិត្យការយល់ដឹងរបស់ខ្លួនអំពី C++។
វាមិនមែនជាការប្រលងទេ ប៉ុន្តែជាឧបករណ៍សម្រាប់រកចន្លោះចំណេះដឹង។
បើអ្នកឆ្លើយខុស សូមត្រឡប់ទៅអានឯកសារ រួចសាកល្បងម្ដងទៀត។

## របៀបប្រើប្រាស់

1. ព្យាយាមឆ្លើយដោយខ្លួនឯង មុនពេលមើលចម្លើយ។
2. កត់ត្រាចំនួនចម្លើយត្រឹមត្រូវ។
3. សម្រាប់ចម្លើយខុស ស្វែងរកហេតុផល។
4. បន្ទាប់ពីសិក្សា សាកល្បងម្ដងទៀត។

## សំណួរគំរូ

**សំណួរ 1:** តើ `auto` ប្រើសម្រាប់អ្វី?

- A) កំណត់ប្រភេទទិន្នន័យដោយស្វ័យប្រវត្តិ
- B) បង្កើតអថេរសកល
- C) បិទការបকប្រែកូដ

ចម្លើយ៖ A

**សំណួរ 2:** តើ `std::vector` ជាអ្វី?

- A) អារេទំហំថេរ
- B) ធុងទិន្នន័យដែលអាចផ្លាស់ប្តូរទំហំបាន
- C) ខ្សែអក្សរ

ចម្លើយ៖ B

**សំណួរ 3:** តើ `nullptr` ត្រូវបានបន្ថែមនៅស្តង់ដារណា?

- A) C++98
- B) C++11
- C) C++17

ចម្លើយ៖ B

## ការផ្ដល់យោបល់

បើលទ្ធផលតិចជាង 60% សូមសិក្សាឡើងវិញនូវជំពូកដែលពាក់ព័ន្ធ។
បើលទ្ធផលល្អ សាកល្បងបញ្ហាសរសេរកូដ ដើម្បីអនុវត្តបន្ថែម។
ការសាកល្បងជាបន្តបន្ទាប់ជួយរក្សាចំណេះដឹងឱ្យនៅស្ថិតស្ថេរ។
