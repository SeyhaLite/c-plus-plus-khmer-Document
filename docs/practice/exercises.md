# លំហាត់តាមជំពូក

```{translation-meta} practice/exercises
```

ការអានឯកសារតែឯងមិនគ្រប់គ្រាន់សម្រាប់ក្លាយជាអ្នកសរសេរ C++ ដែលមានជំនាញទេ។
លំហាត់តាមជំពូកផ្ដល់ឱកាសឱ្យអ្នកអនុវត្តគំនិត ដែលបានរៀន ដោយចាប់ផ្ដើម
ពីមូលដ្ឋានរហូតដល់កម្រិតខ្ពស់។ គោលបំណងមិនមែនឱ្យអ្នកចងចាំចម្លើយទេ
ប៉ុន្តែឱ្យអ្នកអាចសរសេរកូដដែលដំណើរការបាន ហើយអាចពន្យល់ពីហេតុផលបាន។

## របៀបប្រើប្រាស់

សម្រាប់លំហាត់នីមួយៗ អនុវត្តតាមជំហានទាំងនេះ៖

1. អានសេចក្ដីណែនាំ និងការរំពឹងទុក។
2. សរសេរកូដក្នុងឯកសារ `.cpp` ដោយខ្លួនឯង។
3. បកប្រែដោយ `g++ -std=c++17 -Wall -Wextra -pedantic`។
4. ប្រៀបធៀបលទ្ធផលជាមួយ EXPECT ដែលផ្ដល់ឱ្យ។
5. បើមានបញ្ហា សូមពិនិត្យសារកំហុស និងព្យាយាមជួសជុល។

## កម្រិតលំបាក

- **ងាយស្រួល** — អនុវត្តវាក្យសព្ទ និងប្រភេទទិន្នន័យមូលដ្ឋាន។
- **មធ្យម** — ប្រើអនុគមន៍ អារេ ខ្សែអក្សរ និងលំហូរគ្រប់គ្រង។
- **ពិបាក** — ប្រើថ្នាក់ ពុម្ព និងការគ្រប់គ្រងអង្គចងចាំ។

## គោលការណ៍សំខាន់

កុំចម្លងចម្លើយពីអ្នកដទៃភ្លាម។ សាកល្បងសរសេរកូដ បកប្រែ និងដំណើរការ
ដោយខ្លួនឯង។ បើកម្មវិធីបកប្រែបដិសេធកូដ សារកំហុសគឺជាគន្លឹះសម្រាប់រៀន
មិនមែនជាកំហុសរបស់អ្នកទេ។ ការសរសេរកូដដែលមិនដំណើរការ ហើយព្យាយាមជួសជុល
គឺជាផ្នែកសំខាន់នៃការរៀន។

## ឧទាហរណ៍លំហាត់

គណនាផលបូកពី 1 ដល់ n។ បញ្ចូល n ពីស្តង់ដារ input ហើយបង្ហាញផលបូក។

```cpp
int sum_to(int n) {
    int total = 0;
    for (int i = 1; i <= n; ++i) total += i;
    return total;
}
```

កូដខាងក្រោមបង្ហាញការអនុវត្តពេញលេញ រួមទាំងការបញ្ចូល និងការបញ្ចេញ។

## ការពិនិត្យលទ្ធផល

ប្រៀបធៀបលទ្ធផលរបស់អ្នកជាមួយ EXPECT ខាងលើ។ បើលទ្ធផលខុស
សូមពិនិត្យសន្ទស្សន៍រង្វិលជុំ និងតម្លៃចាប់ផ្ដើម។ បើកម្មវិធីបកប្រែបង្ហាញ warning
សូមកែតម្រូវ ព្រោះ warning ជាញឹកញាប់ក្លាយជាកំហុសនៅពេលក្រោយ។
