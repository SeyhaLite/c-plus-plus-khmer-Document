# បញ្ហាសរសេរកូដ

```{translation-meta} practice/challenges
```

បញ្ហាសរសេរកូដផ្ដល់បញ្ហាដែលត្រូវដោះស្រាយដោយកូដ មិនមែនគ្រាន់តែសរសេរវាក្យសព្ទ ទេ។
គោលបំណងគឺបង្កើតសមត្ថភាពវិភាគ រចនាអាល់ហ្គោរីត និងពិនិត្យករណីពិសេស។
បញ្ហានីមួយៗមានការពិពណ៌នា ការរំពឹងទុក និងការណែនាំអំពីការបញ្ចូល និងបញ្ចេញ។

## ជំហានដោះស្រាយបញ្ហា

1. អានបញ្ហាឱ្យបានយល់ ហើយកត់ត្រាតម្រូវការ។
2. រកករណីពិសេស ដូចជា n = 0 ឬ input ទទេ។
3. ជ្រើសរើសធុងទិន្នន័យ និងអាល់ហ្គោរីតត្រឹមត្រូវ។
4. សរសេរកូដ បកប្រែ និងសាកល្បងជាមួយទិន្នន័យគំរូ។
5. ពិនិត្យភាពស្មុគស្មាញ និងបង្កើនប្រសិទ្ធភាពបើចាំបាច់។

## ឧទាហរណ៍បញ្ហា

ស្វែងរកតម្លៃធំបំផុតក្នុងអារេចំនួនគត់។ បញ្ចូលចំនួនធាតុ រួចចំនួនទាំងនោះ។
បង្ហាញតម្លៃធំបំផុត។

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> values = {3, 7, 2, 9, 4};
    auto largest = *std::max_element(values.begin(), values.end());
    std::cout << "max: " << largest << '\n';
    return 0;
}
```

កូដពេញលេញខាងក្រោមប្រើបណ្ណាល័យស្តង់ដារ ដើម្បីស្វែងរកតម្លៃធំបំផុត។

```{literalinclude} ../../examples/practice/challenges.cpp
:language: cpp
```

លទ្ធផល៖

```text
max: 9
```

## ករណីពិសេសដែលត្រូវពិនិត្យ

- អារេមានធាតុតែមួយ។
- តម្លៃអវិជ្ជមានទាំងអស់។
- តម្លៃស្មើគ្នាច្រើន។
- ចំនួនធាតុធំ ដែលត្រូវការប្រសិទ្ធភាព។

## គន្លឹះ

កុំព្យាយាមសរសេរកូដពេញលេញភ្លាម។ សាកល្បងដោះស្រាយដោយដៃសិន
ដើម្បីយល់ពីលំនាំ។ បន្ទាប់មកបកប្រែកូដជាជំហានៗ ហើយសាកល្បង។
ការប្រើ `std::max_element` ឬ `std::sort` ជាញឹកញាប់ងាយស្រួលជាងការសរសេរដោយដៃ
ប៉ុន្តែអ្នកគួរយល់ពីរបៀបដែលវាដំណើរការ។
