# ការផ្តល់មតិ

ឯកសារបច្ចេកទេសល្អត្រូវការការត្រួតពិនិត្យពីអ្នកអាន។ បើអ្នកឃើញបញ្ហា
សូមរាយការណ៍។ យើងផ្តល់អាទិភាពខ្ពស់បំផុតដល់កំហុសបច្ចេកទេស។

## ប្រភេទបញ្ហាដែលគួររាយការណ៍

- **កូដមិនបកប្រែ** ឬលទ្ធផលមិនត្រូវនឹងអ្វីដែលឯកសារបង្ហាញ។
- **ការពន្យល់ខុស** ពីឥរិយាបថរបស់ C++ ឬខុសពីស្តង់ដារ។
- **ស្តង់ដារខុស** ឧទាហរណ៍ លក្ខណៈ C++17 ត្រូវបានសរសេរថាជា C++11។
- **ពាក្យមិនស៊ីសង្វាក់** ជាមួយ [បញ្ជីពាក្យ](glossary.md)។
- **អក្សរខ្មែរខូច** ឬតំណខូច។

## របៀបរាយការណ៍

រាល់ទំព័រមានតំណ «ផ្តល់មតិ ឬរាយការណ៍បញ្ហាសម្រាប់ទំព័រនេះ» នៅក្នុងប្លុក
ស្ថានភាពបកប្រែខាងលើឯកសារ។ តំណនោះនាំអ្នកទៅកាន់ទម្រង់បើកបញ្ហា
(issue) នៅ GitHub បើអ្នកដំឡើងគម្រោងបានកំណត់ `KHMER_CPP_REPO_URL`។

សូមបញ្ចូលព័ត៌មានទាំងនេះក្នុងរបាយការណ៍៖

1. តំណទំព័រ ឬ id ទំព័រ។
2. អ្វីដែលអ្នករំពឹង និងអ្វីដែលអ្នកឃើញ។
3. កម្មវិធីបកប្រែ និងស្តង់ដារ (ឧទាហរណ៍ `g++ 13.3 -std=c++17`)។
4. ប្រភពយោងដែលបញ្ជាក់ថាឯកសារខុស (បើមាន)។

## អ្វីដែលយើងនឹងធ្វើ

- កំហុសបច្ចេកទេសត្រូវបានជួសជុលមុនគេ។ បើការបកប្រែខុស យើងនឹងដកស្លាក
  «បានផ្ទៀងផ្ទាត់» វិញភ្លាមៗ ដើម្បីកុំឱ្យអ្នកអានជឿលើព័ត៌មានខុស។
- យើងមិនបិទបាំងកំហុសដោយការលុបមតិយោបល់ឡើយ។
