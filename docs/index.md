# ឯកសារ C++ ជាភាសាខ្មែរ

គេហទំព័រនេះជាឯកសាររៀន និងឯកសារយោងសម្រាប់ភាសា C++ ដែលសរសេរជាភាសាខ្មែរ។
ខ្លឹមសារទាំងអស់ផ្អែកលើឯកសារផ្លូវការ និងប្រភពបច្ចេកទេសដែលអាចផ្ទៀងផ្ទាត់បាន
ដូចជា [cppreference.com](https://en.cppreference.com/w/),
[isocpp.org](https://isocpp.org/) និង
[សេចក្ដីព្រាងស្តង់ដារ C++](https://eel.is/c++draft/)។

យើងមិនប្រឌិតលក្ខណៈភាសា អនុគមន៍ ឬឥរិយាបថរបស់ C++ ឡើយ។
រាល់ទំព័រមានតំណទៅកាន់ប្រភពដើម និងបញ្ជាក់ស្តង់ដារអប្បបរមាដែលត្រូវការ។

## ចាប់ផ្ដើមពីណា?

- បើអ្នកមិនធ្លាប់ប្រើ C++ សោតទេ សូមចាប់ផ្ដើមពី [C++ ជាអ្វី?](getting-started/what-is-cpp.md)
  រួចបន្តទៅ [កម្មវិធី C++ ដំបូង](getting-started/first-program.md)។
- បើអ្នកចេះភាសាផ្សេងរួចហើយ សូមអាន [វាក្យសម្ព័ន្ធ](basics/syntax.md) និង
  [ប្រភេទទិន្នន័យ](basics/data-types.md) ដើម្បីដឹងពីភាពខុសគ្នា។
- បើអ្នកចង់ដឹងថាឯកសារនេះបានបកប្រែប៉ុន្មានហើយ សូមមើល [វឌ្ឍនភាពបកប្រែ](progress.md)។

## របៀបអានឯកសារនេះ

**ស្លាកស្ថានភាពបកប្រែ។** រាល់ទំព័រមានស្លាកនៅខាងលើបង្ហាញថាតើទំព័រនោះ
បានបកប្រែហើយ បានផ្ទៀងផ្ទាត់បច្ចេកទេសហើយ ឬនៅរង់ចាំ។ ស្លាក «បានផ្ទៀងផ្ទាត់»
មានន័យថាគំរូកូដក្នុងទំព័រត្រូវបានបកប្រែដោយកម្មវិធីបកប្រែពិត
ហើយពាក្យបច្ចេកទេសត្រូវនឹង [បញ្ជីពាក្យ](glossary.md)។

**ជម្រើសស្តង់ដារ C++។** នៅរបារខាងឆ្វេង អ្នកអាចជ្រើសស្តង់ដារ C++
ដើម្បីលាក់លក្ខណៈដែលថ្មីជាងស្តង់ដារនោះ។ ឧទាហរណ៍ បើអ្នកជ្រើស C++11
ទំព័រអំពី `std::ranges` (C++20) នឹងត្រូវលាក់។ នេះជួយអ្នកមិនឱ្យរៀនលក្ខណៈ
ដែលកម្មវិធីបកប្រែរបស់អ្នកមិនគាំទ្រ។

**កូដឧទាហរណ៍។** គំរូកូដទាំងអស់ជាកម្មវិធីពេញលេញដែលអាចបកប្រែ និងដំណើរការបាន។
អ្នកអាចចម្លងកូដដោយចុចប៊ូតុងចម្លងនៅជ្រុងខាងស្ដាំនៃប្លុកកូដ។

## ស្តង់ដារ C++ ដែលឯកសារនេះគាំទ្រ

| ស្តង់ដារ | ស្ថានភាព |
| --- | --- |
| C++98 / C++03 | ចេញផ្សាយជាផ្លូវការ |
| C++11 | ចេញផ្សាយជាផ្លូវការ |
| C++14 | ចេញផ្សាយជាផ្លូវការ |
| C++17 | ចេញផ្សាយជាផ្លូវការ |
| C++20 | ចេញផ្សាយជាផ្លូវការ |
| C++23 | ចេញផ្សាយជាផ្លូវការ |
| C++26 | **ព្រាង** — មិនទាន់ចេញជាស្តង់ដារផ្លូវការ |

លក្ខណៈណាដែលមកពីព្រាង C++26 ត្រូវបានសម្គាល់យ៉ាងច្បាស់ថា «ព្រាង»
ហើយមិនត្រូវរាប់ជាលក្ខណៈស្តង់ដារផ្លូវការឡើយ។
