# ការចងក្រង និងការដំណើរការកម្មវិធី

```{translation-meta} getting-started/compile-and-run
```

ការសរសេរកូដគឺជាជំហានទីមួយ។ ដើម្បីបង្កើតកម្មវិធីដែលអាចដំណើរការបាន
កូដជាទូទៅត្រូវឆ្លងកាត់ការដំណើរការមុន (preprocessing) ការចងក្រង (compilation)
និងការភ្ជាប់ (linking)។

## ពាក្យបញ្ជាមូលដ្ឋាន

```bash
g++ -std=c++17 hello.cpp -o hello
./hello
```

- `g++` ជាកម្មវិធីចងក្រង C++ របស់ GCC។
- `-std=c++17` ជ្រើសស្តង់ដារ C++17។
- `hello.cpp` ជាឯកសារកូដដើម (source file)។
- `-o hello` កំណត់ឈ្មោះឯកសារកម្មវិធីលទ្ធផល។ បើមិនកំណត់ វានឹងបង្កើត `a.out` នៅលើប្រព័ន្ធ Unix-like ជាទូទៅ។
- `./hello` ដំណើរការកម្មវិធីនៅ Linux/macOS។ នៅ Windows អ្នកអាចរត់ `hello.exe`។

## ទិដ្ឋភាពទូទៅនៃដំណើរការបង្កើតកម្មវិធី

ស្តង់ដារ C++ កំណត់ដំណាក់កាលបកប្រែ (translation phases) ច្រើនជាងបី។
ដើម្បីងាយយល់ អ្នកអាចមើលទិដ្ឋភាពទូទៅនៃការងាររបស់ toolchain ជាបីផ្នែកធំៗ៖

1. **ដំណើរការមុន (preprocessing)** — ដោះស្រាយសេចក្ដីបញ្ជា `#include`, `#define`
   និងលក្ខខណ្ឌ `#if`។
2. **ការចងក្រង (compilation)** — ពិនិត្យ និងបម្លែងឯកតាកូដ C++ ទៅជា object code
   ឬទម្រង់កូដកម្រិតទាបផ្សេងទៀត។ កម្មវិធីចងក្រងអាចរាយការណ៍កំហុសវាក្យសម្ព័ន្ធ
   និងប្រភេទទិន្នន័យនៅជំហាននេះ។
3. **ការភ្ជាប់ (linking)** — ភ្ជាប់ object files និងបណ្ណាល័យដែលត្រូវការ
   ដើម្បីបង្កើត executable ឬកម្មវិធីដែលអាចដំណើរការបាន។

បើអ្នកចង់បំបែកការចងក្រង និងការភ្ជាប់ជាពីរពាក្យបញ្ជា៖

```bash
g++ -std=c++17 -c hello.cpp -o hello.o   # ចងក្រងជា object file ដោយមិនភ្ជាប់
g++ hello.o -o hello                     # ភ្ជាប់ object file ទៅជា executable
```

## កូដឧទាហរណ៍៖ ពេលចងក្រង និងពេលដំណើរការ

```{literalinclude} ../../examples/getting-started/compile-and-run.cpp
:language: cpp
```

```bash
g++ -std=c++17 -Wall -Wextra compile-and-run.cpp -o demo
./demo
```

លទ្ធផល៖

```text
compile-time: 5
runtime: 9
```

អថេរ `constexpr` ខាងក្នុងឧទាហរណ៍នេះត្រូវតែមានតម្លៃដែលអាចគណនាបាន
នៅពេលចងក្រង។ ប៉ុន្តែអនុគមន៍ដែលបានសម្គាល់ជា `constexpr` ក៏អាចត្រូវបាន
ហៅនៅពេលកម្មវិធីដំណើរការបានដែរ។ ដូច្នេះ `add(4, 5)` ក្នុងឧទាហរណ៍
ត្រូវបានហៅនៅពេល runtime។

:::{note}
កុំយល់ថា `constexpr` មានន័យថាកម្មវិធីចងក្រងត្រូវគណនាការហៅអនុគមន៍
គ្រប់លើកជាមុនទាំងអស់។ វាអនុញ្ញាតឱ្យប្រើកន្សោមក្នុង context ដែលត្រូវការ
constant expression ហើយការគណនាពិតប្រាកដអាស្រ័យលើរបៀបប្រើកូដ។
:::

## កូដត្រឡប់ (exit code)

កម្មវិធីត្រឡប់លេខទៅប្រព័ន្ធប្រតិបត្តិការ។ នៅ shell អ្នកអាចពិនិត្យវាបាន៖

```bash
./demo
echo $?
```

បើកម្មវិធីត្រឡប់ `0` នោះជាទូទៅមានន័យថាបញ្ចប់ដោយជោគជ័យ។ លេខផ្សេងទៀត
ជាទូទៅប្រើសម្រាប់បង្ហាញករណីបរាជ័យ។ ឧបករណ៍ស្វ័យប្រវត្តិ (CI) ប្រើលេខនេះ
ដើម្បីដឹងថាការធ្វើតេស្តបានជោគជ័យឬអត់។

## ជម្រើសដែលគួរប្រើញឹកញាប់

| ជម្រើស | អត្ថន័យ |
| --- | --- |
| `-Wall -Wextra` | បើកការព្រមានសំខាន់ៗ |
| `-Werror` | ចាត់ទុកការព្រមានជាកំហុស |
| `-O2` | បង្កើនប្រសិទ្ធភាព |
| `-g` | បន្ថែមព័ត៌មានសម្រាប់ debug |
| `-std=c++20` | ជ្រើសស្តង់ដារ C++20 |

សម្រាប់ការរៀន សូមប្រើ `-Wall -Wextra` ដើម្បីជួយរកឃើញបញ្ហាមុនពេលវាក្លាយជា bug។
