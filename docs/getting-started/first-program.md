# កម្មវិធី C++ ដំបូង

## កូដ

```{literalinclude} ../../examples/getting-started/first-program.cpp
:language: cpp
```

រក្សាទុកកូដនេះក្នុងឯកសារឈ្មោះ `hello.cpp` បន្ទាប់មកចងក្រង និងដំណើរការ។

### GCC ឬ Clang (Linux / macOS / MinGW-w64)

```bash
g++ -std=c++17 -Wall -Wextra hello.cpp -o hello
./hello
```

បើប្រើ Clang សូមប្ដូរ `g++` ទៅជា `clang++`។

### MSVC (Windows)

បើក Developer Command Prompt for VS រួចរត់៖

```bat
cl /std:c++17 /W4 /EHsc hello.cpp /Fe:hello.exe
hello.exe
```

លទ្ធផល៖

```text
Hello, world!
```

## ពន្យល់មួយបន្ទាត់ម្ដងៗ

**`#include <iostream>`** — បញ្ចូលឯកសារក្បាល (header) `iostream` ដែលផ្ដល់
`std::cout` សម្រាប់បញ្ចេញអត្ថបទទៅអេក្រង់។ បើគ្មានបន្ទាត់នេះទេ
កម្មវិធីចងក្រងនឹងរាយការណ៍ថាមិនស្គាល់ `std::cout`។

**`int main()`** — នេះជាអនុគមន៍ដែលជាចំណុចចាប់ផ្ដើមរបស់កម្មវិធី។
កម្មវិធី C++ ដែលអាចដំណើរការបានជាទូទៅត្រូវមាន `main` មួយ។ ប្រភេទតម្លៃត្រឡប់គឺ `int`។

**`{` និង `}`** — សម្គាល់ដើម និងចុងនៃតួអនុគមន៍ (function body)។

**`std::cout << "Hello, world!"`** — `std::cout` ជាស្ទ្រីមបញ្ចេញ
(output stream) ដែលភ្ជាប់ទៅ standard output។ ប្រមាណវិធី `<<` បញ្ជូនតម្លៃទៅស្ទ្រីម។
`std::` ជាលំហឈ្មោះ (namespace) របស់បណ្ណាល័យស្តង់ដារ។

**`<< std::endl`** — `std::endl` បញ្ចូលតួអក្សរចុះបន្ទាត់ថ្មី ហើយបញ្ជូនទិន្នន័យ
ចេញភ្លាម (flush)។ ក្នុងកូដប្រចាំថ្ងៃ គេជាញឹកញាប់ប្រើ `'\\n'` ជំនួស
ព្រោះវាចុះបន្ទាត់ថ្មីដោយមិនបង្ខំ flush រាល់ដង។

**`return 0;`** — តម្លៃត្រឡប់ទៅប្រព័ន្ធប្រតិបត្តិការ។ `0` មានន័យថាកម្មវិធី
បញ្ចប់ដោយជោគជ័យ។

:::{note}
ក្នុងអនុគមន៍ `main` ជាក់លាក់ បើអ្នកមិនសរសេរ `return` នៅចុងអនុគមន៍ទេ
C++ ចាត់ទុកដូចជាអ្នកបានត្រឡប់ `0`។ ការសរសេរវាឱ្យច្បាស់ក៏អាចជួយអ្នករៀន
ឱ្យយល់ពីតម្លៃត្រឡប់ផងដែរ។
:::

## បញ្ហាដែលអ្នកចាប់ផ្ដើមជួបញឹកញាប់

**ភ្លេចសញ្ញា `;`** — សេចក្ដីថ្លែងការណ៍នីមួយៗក្នុង C++ ត្រូវបញ្ចប់ដោយ `;`។
សារកំហុសអាចចង្អុលទៅបន្ទាត់បន្ទាប់ ដែលធ្វើឱ្យអ្នកយល់ច្រឡំ។

**`cout` ដោយគ្មាន `std::`** — បើអ្នកសរសេរ `cout` តែម្នាក់ឯង កម្មវិធីចងក្រង
អាចរាយការណ៍ថាមិនស្គាល់ឈ្មោះនេះ។ ដំណោះស្រាយងាយគឺសរសេរ `std::cout`។

**ខ្វះ `#include <iostream>`** — បើប្រើ `std::cout` ឬ `std::cin`
ត្រូវបញ្ចូល `<iostream>`។ បើប្រើ `std::string` ឬ `std::wstring`
ត្រូវបញ្ចូល `<string>`។

**តើ `wchar_t` ត្រូវការ header ទេ?** — ទេ។ `wchar_t` ជាប្រភេទទិន្នន័យ
ដែលមានស្រាប់ក្នុងភាសា C++ (built-in type) ដូច្នេះមិនត្រូវការ `#include`
ដើម្បីប្រកាសអថេរប្រភេទនេះទេ។ ប៉ុន្តែប្រភេទ `std::wstring` ស្ថិតក្នុង
បណ្ណាល័យស្តង់ដារ ហើយត្រូវការ `#include <string>`។

**ប្រើ `gcc` ជំនួស `g++`** — `gcc` អាចចងក្រងឯកសារប្រភព C++ បាន
បើកំណត់ជម្រើសត្រឹមត្រូវ ប៉ុន្តែវាមិនភ្ជាប់ C++ standard library ដោយស្វ័យប្រវត្តិ
ដូច `g++` ទេ។ សម្រាប់អ្នកចាប់ផ្ដើម សូមប្រើ `g++` សម្រាប់ C++។
