## កូដ

```{literalinclude} ../../examples/getting-started/first-program.cpp
:language: cpp
```

រក្សាទុកកូដនេះក្នុងឯកសារឈ្មោះ `hello.cpp` បន្ទាប់មកបកប្រែ និងដំណើរការ៖

```bash
g++ -std=c++17 -Wall -Wextra hello.cpp -o hello
./hello
```

លទ្ធផល៖

```text
Hello, world!
```

## ពន្យល់មួយបន្ទាត់ម្ដងៗ

**`#include <iostream>`** — បញ្ចូលឯកសារក្បាល (header) `iostream` ដែលផ្ដល់
`std::cout` សម្រាប់បញ្ចេញអត្ថបទទៅអេក្រង់។ បើគ្មានបន្ទាត់នេះទេ
កម្មវិធីបកប្រែនឹងរាយការណ៍ថាមិនស្គាល់ `std::cout`។

**`int main()`** — នេះជាចំណុចចាប់ផ្ដើមរបស់កម្មវិធី។ គ្រប់កម្មវិធី C++
ត្រូវមានអនុគមន៍ `main` តែមួយ។ ប្រភេទតម្លៃត្រឡប់គឺ `int`។

**`{` និង `}`** — សម្គាល់ដែនកំណត់នៃតួអង្គកម្មវិធី (function body)។

**`std::cout << "Hello, world!"`** — `std::cout` ជាស្ទ្រីមបញ្ចេញ (output stream)
ដែលភ្ជាប់ទៅ standard output។ ប្រមាណវិធី `<<` បញ្ជូនតម្លៃទៅស្ទ្រីម។
`std::` ជាលំហឈ្មោះ (namespace) របស់បណ្ណាល័យស្តង់ដារ។

**`<< std::endl`** — `std::endl` បញ្ចូលតួអក្សរថ្មីបន្ទាត់ ហើយបញ្ជូនទិន្នន័យចេញភ្លាម
(flush)។ ក្នុងកូដប្រចាំថ្ងៃ គេច្រើនប្រើ `'\n'` ព្រោះវាមិនបង្ខំ flush
ដូច្នេះលឿនជាង។

**`return 0;`** — តម្លៃត្រឡប់ទៅប្រព័ន្ធប្រតិបត្តិការ។ `0` មានន័យថាកម្មវិធី
បញ្ចប់ដោយជោគជ័យ។

:::{note}
ចំពោះ `main` ជាក់លាក់ បើអ្នកមិនសរសេរ `return` ទេ កម្មវិធីបកប្រែនឹងចាត់ទុកថា
អ្នកត្រឡប់ `0`។ ប៉ុន្តែការសរសេរវាឱ្យច្បាស់គឺជាទម្លាប់ល្អ និងអានងាយជាង។
:::

## បញ្ហាដែលអ្នកចាប់ផ្ដើមជួបញឹកញាប់

**ភ្លេចសញ្ញា `;`** — សេចក្តីថ្លែងការណ៍នីមួយៗក្នុង C++ ត្រូវបញ្ចប់ដោយ `;`។
សារកំហុសអាចចង្អុលទៅបន្ទាត់បន្ទាប់ ដែលធ្វើឱ្យអ្នកយល់ច្រឡំ។

**`cout` ដោយគ្មាន `std::`** — បើអ្នកសរសេរ `cout` តែម្នាក់ឯង កម្មវិធីបកប្រែនឹងរាយការណ៍ថា
មិនស្គាល់ឈ្មោះនេះ។ ដំណោះស្រាយ៖ សរសេរ `std::cout` ឬប្រើ `using std::cout;`
នៅក្នុងដែនកំណត់តូចមួយ។

**`#include <iostream>` ខ្វះ** — សារកំហុស «`cout` was not declared in this scope»។
`wchar_t` ឬ `std::string` ក៏ត្រូវការ header រៀងៗខ្លួនដែរ (`<string>`)។

**ប្រើ `gcc` ជំនួស `g++`** — `gcc` មិនភ្ជាប់បណ្ណាល័យ C++ ស្តង់ដារដោយស្វ័យប្រវត្តិទេ
ដូច្នេះអ្នកនឹងឃើញកំហុសពេលភ្ជាប់ (link error)។ សម្រាប់ C++ ត្រូវប្រើ `g++`។
