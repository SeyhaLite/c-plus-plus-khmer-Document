# ប្រវត្តិ និងស្តង់ដារ C++

## បន្ទាត់ពេលវេលា

| ឆ្នាំ | ព្រឹត្តិការណ៍ |
| --- | --- |
| 1979 | Bjarne Stroustrup ចាប់ផ្ដើម «C with Classes» នៅ Bell Labs |
| 1983 | ប្ដូរឈ្មោះជា C++ |
| 1985 | ចេញផ្សាយសៀវភៅ *The C++ Programming Language* និងកំណែ C++ ដំបូងៗ |
| 1989 | C++ 2.0 បន្ថែម multiple inheritance និង abstract classes |
| 1998 | **C++98** — ស្តង់ដារ ISO ដំបូង (ISO/IEC 14882:1998) |
| 2003 | **C++03** — កំណែសម្រួល C++98 ដែលផ្ដោតលើការកែបញ្ហា និងភាពច្បាស់លាស់ មិនមែនជាកំណែបន្ថែមលក្ខណៈធំៗទេ |
| 2011 | **C++11** — បន្ថែម `auto`, lambdas, move semantics, `nullptr` និងខ្សែស្រឡាយ |
| 2014 | **C++14** — កែលម្អលើ C++11 ដូចជា generic lambdas |
| 2017 | **C++17** — បន្ថែម structured bindings, `std::optional`, `std::filesystem` និង `if constexpr` |
| 2020 | **C++20** — បន្ថែម concepts, ranges, coroutines និង modules ព្រមទាំងកែលម្អ `constexpr` |
| 2023 | **C++23** — ឈ្មោះកំណែស្តង់ដារ; ឯកសារ ISO/IEC 14882:2024 ត្រូវបានបោះពុម្ពនៅឆ្នាំ 2024 |
| 2026 | **C++26** — បានឈានដល់ដំណាក់កាល Draft International Standard (DIS) សម្រាប់ការពិនិត្យ និងអនុម័តតាមដំណើរការ ISO |

## របៀបអានតារាងនេះ

**C++03 ជាកំណែសម្រួល C++98។** វាផ្ដោតលើការកែបញ្ហា និងការបញ្ជាក់ច្បាប់
ឱ្យច្បាស់ជាងមុន។ ដូច្នេះឯកសារបច្ចេកទេសជាច្រើនសរសេររួមគ្នាថា «C++98/03»។

**ស្តង់ដារថ្មីៗមានគោលដៅវដ្ដប្រហែល ៣ ឆ្នាំ។** ចាប់ពី C++11 មក គម្រោងស្តង់ដារ
បានប្រើវដ្ដដែលជាទូទៅមានចន្លោះប្រហែលបីឆ្នាំ។ នេះជាគោលដៅអភិវឌ្ឍន៍ មិនមែន
ការធានាថាកំណែថ្មីនឹងចេញទៀងទាត់តាមកាលបរិច្ឆេទដាច់ខាតទេ។

**C++23 មានឈ្មោះកំណែឆ្នាំ 2023 ប៉ុន្តែឯកសារ ISO ចេញផ្សាយនៅឆ្នាំ 2024។**
កុំច្រឡំឆ្នាំក្នុងឈ្មោះកំណែជាមួយឆ្នាំបោះពុម្ពឯកសារ ISO។

**ស្ថានភាព C++26 គិតត្រឹមថ្ងៃទី 14 ខែវិច្ឆិកា ឆ្នាំ 2026។** ISO បង្ហាញថា
ឯកសារ Draft International Standard (DIS) សម្រាប់ ISO/IEC 14882 ជំនាន់បន្ទាប់
បានបិទការបោះឆ្នោតនៅថ្ងៃទី 24 ខែតុលា ឆ្នាំ 2026។ របាយការណ៍ពេញលេញត្រូវបាន
បញ្ជូនត្រឡប់ទៅគណៈកម្មាធិការបច្ចេកទេស ឬអនុគណៈកម្មាធិការ ដើម្បីបន្តការងារ។
ដូច្នេះ C++26 នៅតែជាសេចក្ដីព្រាង មិនមែនជាស្តង់ដារ ISO ដែលបានបោះពុម្ពចុងក្រោយទេ។
លក្ខណៈពិសេស និងការគាំទ្ររបស់កម្មវិធីចងក្រងអាចខុសគ្នាតាមកំណែ។

## ម៉ាក្រូ `__cplusplus`

កម្មវិធីចងក្រងកំណត់ម៉ាក្រូ `__cplusplus` ដើម្បីបង្ហាញស្តង់ដារភាសាដែលកំពុងប្រើ៖

| ស្តង់ដារ | តម្លៃ `__cplusplus` |
| --- | --- |
| C++98 / C++03 | `199711L` |
| C++11 | `201103L` |
| C++14 | `201402L` |
| C++17 | `201703L` |
| C++20 | `202002L` |
| C++23 | `202302L` |

```{literalinclude} ../../examples/getting-started/history.cpp
:language: cpp
```

លទ្ធផលនៅពេលចងក្រងដោយ `-std=c++17`៖

```text
__cplusplus = 201703
structured bindings and if constexpr are available
```

:::{warning}
MSVC មិនកំណត់ `__cplusplus` តាមស្តង់ដារបច្ចុប្បន្នដោយលំនាំដើមទេ។
បើកូដរបស់អ្នកពិនិត្យម៉ាក្រូនេះ សូមបន្ថែមជម្រើស `/Zc:__cplusplus`។
MSVC ក៏មានម៉ាក្រូ `_MSVC_LANG` សម្រាប់ពិនិត្យកំណែភាសាដែលបានជ្រើសរើស។
:::

## ហេតុអ្វីរឿងនេះសំខាន់សម្រាប់អ្នក?

កូដដែលប្រើលក្ខណៈ C++17 នឹងមិនអាចចងក្រងដោយជ្រើសស្តង់ដារ C++11 បានទេ។
បើអ្នកឃើញសារកំហុសដូចជា «`if constexpr` only available with -std=c++17»
នោះមានន័យថា អ្នកត្រូវជ្រើសស្តង់ដារថ្មីជាងនេះ (មើល
[ការចងក្រង និងការដំណើរការ](compile-and-run.md))។
