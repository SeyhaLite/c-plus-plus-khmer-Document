## និយមន័យ

C++ គឺជាភាសាសរសេរកម្មវិធីប្រភេទបកប្រែ (compiled language) ដែលមានប្រភេទទិន្នន័យ
ច្បាស់លាស់ (statically typed) និងគាំទ្រច្រើនទម្រង់នៃការសរសេរកម្មវិធី
(multi-paradigm)។ កូដ C++ ត្រូវបកប្រែទៅជាកូដម៉ាស៊ីនដោយកម្មវិធីបកប្រែ (compiler)
មុនពេលកម្មវិធីដំណើរការ។

ភាសានេះបង្កើតឡើងដោយ Bjarne Stroustrup នៅ Bell Labs ដោយចាប់ផ្ដើមពីភាសា C
នៅឆ្នាំ 1979 ក្រោមឈ្មោះ «C with Classes» ហើយប្ដូរឈ្មោះជា C++ នៅឆ្នាំ 1983។
ចាប់ពីឆ្នាំ 1998 មក C++ ត្រូវបានគ្រប់គ្រងដោយគណៈកម្មាធិការស្តង់ដារ
ISO/IEC JTC1/SC22/WG21 ហើយមានស្តង់ដារចេញផ្សាយជាបន្តបន្ទាប់ (មើល
[ប្រវត្តិ និងស្តង់ដារ](history.md))។

## លក្ខណៈសំខាន់ៗ

**ប្រភេទទិន្នន័យច្បាស់លាស់។** អថេរមួយមានប្រភេទដែលគេស្គាល់នៅពេលបកប្រែ
ដូចជា `int` ឬ `double`។ កម្មវិធីបកប្រែអាចចាប់កំហុសបានមុនពេលកម្មវិធីដំណើរការ។

**គ្មានការចំណាយលើអ្វីដែលអ្នកមិនប្រើ។** C++ ធ្វើតាមគោលការណ៍ «zero-overhead
principle» ដែល Stroustrup ពន្យល់ថា៖ អ្វីដែលអ្នកមិនប្រើ អ្នកមិនចំណាយ
(what you don't use, you don't pay for) ហើយអ្វីដែលអ្នកប្រើ អ្នកមិនអាចសរសេរដោយដៃ
ឱ្យប្រសើរជាងនេះបានឡើយ។

**ការគ្រប់គ្រងអង្គចងចាំច្បាស់លាស់។** អ្នកសម្រេចថាពេលណាបង្កើត និងពេលណាបំផ្លាញវត្ថុ។
យន្តការ RAII ភ្ជាប់ជីវិតរបស់ធនធាន (ឯកសារ អង្គចងចាំ ចំណុចប្រទាក់) ទៅនឹង
ជីវិតរបស់វត្ថុ ដូច្នេះធនធានត្រូវបានដោះលែងដោយស្វ័យប្រវត្តិ។

**ការសរសេរកម្មវិធីច្រើនទម្រង់។** អ្នកអាចសរសេរបែបនីតិវិធី (procedural)
បែបវត្ថុ (object-oriented) និងបែបទូទៅ (generic) ក្នុងភាសាតែមួយ។

**ការបកប្រែទៅកូដម៉ាស៊ីន។** កម្មវិធី C++ ដំណើរការដោយផ្ទាល់លើប្រព័ន្ធប្រតិបត្តិការ
ដោយមិនត្រូវការ virtual machine ដូចភាសាខ្លះ ដូច្នេះវាលឿន និងគ្រប់គ្រងធនធានបានល្អ។

## តើ C++ ខុសពី C យ៉ាងណា?

C++ ចាប់កំណើតពី C ហើយរក្សាវាក្យសម្ព័ន្ធស្ទើរតែទាំងអស់របស់ C ប៉ុន្តែ
**C++ មិនមែនជា superset ដាច់ខាតរបស់ C ទេ**។ កូដ C ខ្លះមិនបកប្រែជា C++
ដូចដើម ឧទាហរណ៍ ការបំប្លែង `void*` ដោយស្វ័យប្រវត្តិ ឬការប្រើពាក្យដែលក្លាយជា
ពាក្យគន្លឹះក្នុង C++ ដូចជា `class` និង `new`។ C++ បន្ថែមថ្នាក់ ពុម្ព ករណីលើកលែង
លំហឈ្មោះ និងបណ្ណាល័យស្តង់ដារធំទូលាយ។

## តើគេប្រើ C++ នៅឯណា?

- ប្រព័ន្ធប្រតិបត្តិការ និងដ្រាយវ័រ
- ហ្គេម និង engine ហ្គេម
- កម្មវិធីរុករកគេហទំព័រ និងកម្មវិធី desktop
- ការគណនាវិទ្យាសាស្ត្រ និង HPC
- ប្រព័ន្ធហិរញ្ញវត្ថុ និងម៉ាស៊ីនបម្រើដែលត្រូវការល្បឿន
- ឧបករណ៍បង្កប់ (embedded) ដែលមានធនធានកំណត់

:::{note}
ឯកសារនេះពន្យល់តែ C++ ស្តង់ដារប៉ុណ្ណោះ។ លក្ខណៈពិសេសរបស់កម្មវិធីបកប្រែនីមួយៗ
(compiler extensions) មិនត្រូវបានបង្រៀននៅទីនេះឡើយ ព្រោះវាមិនអាចផ្ទេរទៅ
កម្មវិធីបកប្រែផ្សេងបាន។
:::
