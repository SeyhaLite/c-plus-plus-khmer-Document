# C++ ជាអ្វី?

## និយមន័យ

C++ គឺជាភាសាសរសេរកម្មវិធីដែលជាទូទៅត្រូវបានចងក្រង (compiled language)។
វាមានប្រភេទទិន្នន័យច្បាស់លាស់ (statically typed) និងគាំទ្ររបៀបសរសេរកម្មវិធី
ច្រើនប្រភេទ (multi-paradigm)។

កូដ C++ ត្រូវបានដំណើរការដោយកម្មវិធីចងក្រង (compiler)។ ជាធម្មតា កម្មវិធីចងក្រង
បង្កើតឯកសារ object code ហើយកម្មវិធីភ្ជាប់ (linker) ភ្ជាប់ឯកសារទាំងនោះជាមួយ
បណ្ណាល័យ ដើម្បីបង្កើតកម្មវិធីដែលអាចដំណើរការបាន។ ដូច្នេះ ការចងក្រង និងការភ្ជាប់
ជាជំហានខុសគ្នា (មើល [ការចងក្រង និងការដំណើរការ](compile-and-run.md))។

ភាសានេះបង្កើតឡើងដោយ Bjarne Stroustrup នៅ Bell Labs ដោយចាប់ផ្ដើមពីភាសា C
នៅឆ្នាំ 1979 ក្រោមឈ្មោះ «C with Classes» ហើយប្ដូរឈ្មោះជា C++ នៅឆ្នាំ 1983។
ស្តង់ដារភាសាត្រូវបានអភិវឌ្ឍដោយគណៈកម្មាធិការ ISO/IEC JTC1/SC22/WG21
(មើល [ប្រវត្តិ និងស្តង់ដារ](history.md))។

## លក្ខណៈសំខាន់ៗ

**ប្រភេទទិន្នន័យច្បាស់លាស់។** អថេរមួយមានប្រភេទដែលកំណត់ដោយកូដ ដូចជា
`int` ឬ `double`។ កម្មវិធីចងក្រងអាចរកឃើញកំហុសប្រភេទទិន្នន័យមួយចំនួន
មុនពេលកម្មវិធីដំណើរការ។ វាមិនមានន័យថាកម្មវិធីចងក្រងអាចរកឃើញកំហុសគ្រប់ប្រភេទទេ។

**គោលការណ៍ Zero-overhead។** គោលការណ៍នេះមានគោលដៅកុំឱ្យអ្នកត្រូវចំណាយ
ធនធានសម្រាប់លក្ខណៈពិសេសដែលអ្នកមិនប្រើ។ វាជាគោលដៅរចនារបស់ C++ មិនមែនជា
ការធានាថាកូដគ្រប់កម្មវិធីនឹងលឿនជាងភាសាផ្សេងទេ។

**ការគ្រប់គ្រងធនធាន។** C++ ផ្ដល់វិធីគ្រប់គ្រងអង្គចងចាំ ឯកសារ និងធនធានផ្សេងៗ។
យន្តការ RAII ភ្ជាប់អាយុកាលរបស់ធនធានទៅនឹងអាយុកាលរបស់វត្ថុ ដើម្បីឱ្យធនធាន
ត្រូវបានដោះលែងដោយស្វ័យប្រវត្តិ នៅពេលវត្ថុចាកចេញពីដែនកំណត់របស់វា។

**ការសរសេរកម្មវិធីច្រើនរបៀប។** អ្នកអាចសរសេរបែបនីតិវិធី (procedural)
បែបវត្ថុ (object-oriented) និងបែបទូទៅ (generic) ក្នុងភាសាតែមួយ។

**ការបង្កើតកម្មវិធី Native។** កម្មវិធីចងក្រង C++ ជាទូទៅអាចបង្កើតកម្មវិធី
ដែលដំណើរការជា native code លើប្រព័ន្ធគោលដៅ ដោយមិនចាំបាច់ប្រើ virtual machine
ជាផ្នែកចាំបាច់របស់ភាសា។ ល្បឿន និងការប្រើធនធានអាស្រ័យលើកូដ ការកំណត់
កម្មវិធីចងក្រង បណ្ណាល័យ និងឧបករណ៍ដែលប្រើ។

## តើ C++ ខុសពី C យ៉ាងណា?

C++ ចាប់កំណើតពី C ហើយមានវាក្យសម្ព័ន្ធស្រដៀងគ្នាច្រើន ប៉ុន្តែ
**C++ មិនមែនជា superset ដាច់ខាតរបស់ C ទេ**។ កូដ C ខ្លះមិនអាចប្រើក្នុង C++
ដោយមិនកែប្រែបានទេ។ ឧទាហរណ៍ ការបម្លែងពី `void*` ទៅ pointer ប្រភេទផ្សេង
ក្នុង C មិនមានការបម្លែងដោយស្វ័យប្រវត្តិដូចគ្នាក្នុង C++ ទេ។ C++ ក៏មានពាក្យគន្លឹះ
ផ្ទាល់ខ្លួន ដូចជា `class` និង `new` ផងដែរ។

C++ បន្ថែមថ្នាក់ ពុម្ព ករណីលើកលែង លំហឈ្មោះ និងឧបករណ៍ជាច្រើនក្នុងបណ្ណាល័យស្តង់ដារ។

## តើគេប្រើ C++ នៅឯណា?

- ប្រព័ន្ធប្រតិបត្តិការ និងកម្មវិធីបញ្ជាឧបករណ៍
- ហ្គេម និង game engine
- កម្មវិធីរុករកគេហទំព័រ និងកម្មវិធី desktop
- ការគណនាវិទ្យាសាស្ត្រ និង HPC
- ប្រព័ន្ធហិរញ្ញវត្ថុ និងម៉ាស៊ីនបម្រើដែលត្រូវការគ្រប់គ្រងធនធានបានល្អ
- ឧបករណ៍បង្កប់ (embedded) ដែលមានធនធានកំណត់

:::{note}
ឯកសារនេះពន្យល់ C++ តាមស្តង់ដារ។ កម្មវិធីចងក្រងនីមួយៗអាចមានលក្ខណៈ
បន្ថែមផ្ទាល់ខ្លួន (compiler extensions) ដែលមិនចាំបាច់ដំណើរការដូចគ្នាលើ
កម្មវិធីចងក្រងផ្សេងទៀតទេ។
:::
