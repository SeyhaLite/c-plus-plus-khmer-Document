# ចាប់ផ្ដើម

ផ្នែកនេះនាំអ្នកពីចំណុចសូន្យទៅកម្មវិធី C++ ដំបូងដែលអ្នកអាចចងក្រង និងដំណើរការបានពិត។
អ្នកមិនត្រូវការចំណេះដឹង C++ ពីមុនទេ ប៉ុន្តែគួរដឹងពីការប្រើប្រាស់ terminal មូលដ្ឋាន
(បើកកម្មវិធី និងរត់ពាក្យបញ្ជា)។

## អ្វីដែលអ្នកនឹងទទួលបាន

- យល់ថា C++ ជាអ្វី និងហេតុអ្វីវានៅតែសំខាន់។
- ដឹងប្រវត្តិស្តង់ដារ ដើម្បីយល់ថាហេតុអ្វីកូដខ្លះត្រូវការ `-std=c++17`។
- ដំឡើងកម្មវិធីចងក្រង (compiler) ហើយផ្ទៀងផ្ទាត់ថាវាដំណើរការ។
- សរសេរ ចងក្រង និងដំណើរការកម្មវិធីដំបូងរបស់អ្នក។
