# if និង else

```{translation-meta} control-flow/if-else
```

`if` ប្រតិបត្តិប្លុកកូដមួយ លុះត្រាតែលក្ខខណ្ឌ (condition) ជាពិត។

## រូបមន្តមូលដ្ឋាន

```cpp
if (condition) {
    // ប្រតិបត្តិ បើ condition ជាពិត
} else {
    // ប្រតិបត្តិ បើ condition ជាមិនពិត
}
```

លក្ខខណ្ឌត្រូវមានប្រភេទដែលអាចបំប្លែងជា `bool`។ តម្លៃលេខដែលមិនសូន្យគឺពិត។

## ខ្សែសង្វាក់ else if

```cpp
int score = 78;

if (score >= 90) {
    std::cout << "A\n";
} else if (score >= 80) {
    std::cout << "B\n";
} else if (score >= 70) {
    std::cout << "C\n";
} else {
    std::cout << "F\n";
}
```

លក្ខខណ្ឌត្រូវពិនិត្យតាមលំដាប់ពីលើចុះក្រោម ហើយប្លុកដំបូងដែលពិតត្រូវប្រតិបត្តិ។
ដូច្នេះលំដាប់មានសារៈសំខាន់៖ បើអ្នកដាក់ `score >= 70` មុន `score >= 90`
នោះពិន្ទុ 95 នឹងទទួលបាន «C» ដោយខុស។

## កំហុសញឹកញាប់៖ `=` ជំនួស `==`

```cpp
int x = 0;
if (x = 5) {           // ខុស! នេះដាក់តម្លៃ 5 ហើយលក្ខខណ្ឌក្លាយជាពិត
    // ...
}
if (x == 5) {          // ត្រូវ — ប្រៀបធៀប
    // ...
}
```

កម្មវិធីបកប្រែជាច្រើនព្រមានអំពីរឿងនេះដោយ `-Wall`។ នេះជាហេតុផលមួយ
ដែលអ្នកគួរបើកការព្រមានជានិច្ច។

## តែងតែប្រើវង់ក្រចកអង្គុយ

```cpp
if (ready)
    start();      // បាន ប៉ុន្តែងាយមានបញ្ហាពេលបន្ថែមបន្ទាត់
```

បើអ្នកបន្ថែមបន្ទាត់ទីពីរក្រោយមក វានឹងមិននៅក្នុង `if` ទេ។ ដូច្នេះសូមសរសេរ
វង់ក្រចកអង្គុយជានិច្ច ទោះមានបន្ទាត់តែមួយក៏ដោយ។

## លក្ខណៈថ្មីៗ

**`if` ជាមួយការចាប់ផ្ដើមតម្លៃ (C++17)។** អ្នកអាចប្រកាសអថេរក្នុងលក្ខខណ្ឌ៖

```cpp
if (int remaining = queue_size(); remaining > 0) {
    // remaining មានតែក្នុងប្លុកនេះ
}
```

**`if constexpr` (C++17)។** វាយតម្លៃលក្ខខណ្ឌនៅពេលបកប្រែ ហើយជ្រើសយក
សាខាតែមួយ។ វាមានប្រយោជន៍ក្នុងកូដទូទៅ (templates)។

**`constexpr` ក្នុង C++20។** C++20 អនុញ្ញាត `if constexpr` ក្នុងបរិបទកាន់តែច្រើន
និងបន្ថែម `std::is_constant_evaluated()`។
