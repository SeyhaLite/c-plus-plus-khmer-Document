# ប្រភព និងអាជ្ញាបណ្ណ

## ប្រភពផ្លូវការ

យើងយោងតែលើប្រភពដែលមានសិទ្ធិអំណាចខាង C++ ប៉ុណ្ណោះ៖

- [cppreference.com](https://en.cppreference.com/w/) — ឯកសារយោង C និង C++ ស្តង់ដារ
- [isocpp.org](https://isocpp.org/) — គេហទំព័រផ្លូវការរបស់គណៈកម្មាធិការស្តង់ដារ C++
- [eel.is/c++draft](https://eel.is/c++draft/) — សេចក្ដីព្រាងស្តង់ដារ C++ បច្ចុប្បន្ន
- [WG21](https://www.open-std.org/jtc1/sc22/wg21/) — គណៈកម្មាធិការ ISO/IEC JTC1/SC22/WG21

រាល់ទំព័រដែលបានបកប្រែមានបញ្ជីប្រភពរៀងៗខ្លួននៅខាងលើឯកសារ

## អាជ្ញាបណ្ណ

**អត្ថបទខ្មែរ និងគំរូកូដ** ក្នុងគម្រោងនេះចេញផ្សាយក្រោម
[Creative Commons Attribution-ShareAlike 3.0 Unported (CC BY-SA 3.0)](https://creativecommons.org/licenses/by-sa/3.0/)។
អ្នកអាចចម្លង កែប្រែ និងចែកចាយបាន ដរាបណាអ្នកផ្ដល់ការទទួលស្គាល់
និងចេញផ្សាយការកែប្រែក្រោមអាជ្ញាបណ្ណដូចគ្នា។

**cppreference.com** ចេញផ្សាយខ្លឹមសាររបស់ខ្លួនក្រោម
CC BY-SA 3.0 Unported និង GNU Free Documentation License (GFDL)។
លក្ខខណ្ឌរបស់ពួកគេសុំឱ្យយើងភ្ជាប់តំណត្រឡប់ទៅ cppreference.com
ដើម្បីឱ្យអ្នកអានដឹងកន្លែងទទួលបានឯកសារថ្មីបំផុត។ យើងធ្វើដូច្នេះនៅគ្រប់ទំព័រ។

**ស្តង់ដារ C++** ជាឯកសាររក្សាសិទ្ធិដោយ ISO/IEC។
យើងមិនចម្លងអត្ថបទស្តង់ដារទាំងស្រុងឡើយ។ យើងសរសេរការពន្យល់ថ្មីជាភាសាខ្មែរ
ដោយផ្អែកលើការអានស្តង់ដារ និងឯកសារយោងសាធារណៈ។

## អ្វីដែលយើងមិនធ្វើ

- យើងមិនចម្លងអត្ថបទ cppreference ទាំងទំព័រមកដាក់ក្នុងគេហទំព័រនេះឡើយ។
  យើងបកប្រែ និងសរសេរឡើងវិញជាភាសាខ្មែរ ដោយរក្សាតំណទៅប្រភពដើម។
- យើងមិនបង្ហាញលេខស្ថិតិដែលមិនផ្អែកលើឯកសារពិតឡើយ។
- យើងមិនដាក់ស្លាក «ស្តង់ដារ» លើលក្ខណៈព្រាង (C++26) ឡើយ។
