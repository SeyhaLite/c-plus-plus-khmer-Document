# កម្មវិធីនិយមវត្ថុ

កម្មវិធីនិយមវត្ថុ (Object-Oriented Programming) គឺជាវិធីរៀបចំកម្មវិធីដោយដាក់
ទិន្នន័យ និងប្រតិបត្តិការលើទិន្នន័យនោះឱ្យនៅជាមួយគ្នាក្នុងឯកតាដែលហៅថា
**ថ្នាក់** (class)។

C++ គាំទ្រលក្ខណៈសំខាន់បួន៖

- **ការខ្ចប់ទិន្នន័យ** (encapsulation) — លាក់រចនាសម្ព័ន្ធខាងក្នុង។
- **មរតក** (inheritance) — បង្កើតថ្នាក់ថ្មីពីថ្នាក់ដែលមានស្រាប់។
- **ពហុរូបភាព** (polymorphism) — ហៅប្រតិបត្តិការដូចគ្នាលើវត្ថុផ្សេងគ្នា។
- **អរូបីកម្ម** (abstraction) — បង្ហាញតែចំណុចប្រទាក់ចាំបាច់។
