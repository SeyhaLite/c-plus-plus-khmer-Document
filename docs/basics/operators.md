# ប្រមាណវិធី (Operators)

```{translation-meta} basics/operators
```

ប្រមាណវិធី (Operator) គឺជានិមិត្តសញ្ញាដែលធ្វើប្រតិបត្តិការលើតម្លៃមួយ ឬច្រើន។
ឧទាហរណ៍ `+` បូកតម្លៃពីរ ហើយ `!` បដិសេធតម្លៃប៊ូលីន។

## ប្រមាណវិធីនព្វន្ធ

| ប្រមាណវិធី | អត្ថន័យ | ឧទាហរណ៍ |
| --- | --- | --- |
| `+` | បូក | `3 + 2` → `5` |
| `-` | ដក | `3 - 2` → `1` |
| `*` | គុណ | `3 * 2` → `6` |
| `/` | ចែក | `7 / 2` → `3` (ចំនួនគត់) |
| `%` | សំណល់ | `7 % 2` → `1` |

:::{warning}
ការចែកចំនួនគត់ពីរនឹងបាត់បង់ផ្នែកទសភាគ។ `7 / 2` គឺ `3` មិនមែន `3.5` ទេ។
បើអ្នកចង់បានលទ្ធផលពិត ត្រូវបំប្លែងយ៉ាងតិចមួយទៅ `double` ដោយ `static_cast<double>(7) / 2`។
:::

ចំពោះចំនួនគត់អវិជ្ជមាន ការចែកកាត់ចោលទៅខាងសូន្យ៖ `-7 / 2 == -3` ហើយ
`-7 % 2 == -1`។ នេះជាឥរិយាបថដែលស្តង់ដារកំណត់ចាប់ពី C++11។

## ប្រមាណវិធីប្រៀបធៀប និងតក្កវិជ្ជា

| ប្រមាណវិធី | អត្ថន័យ |
| --- | --- |
| `==`, `!=` | ស្មើ, មិនស្មើ |
| `<`, `>`, `<=`, `>=` | តូចជាង, ធំជាង, ... |
| `&&` | និង (and) |
| `\|\|` | ឬ (or) |
| `!` | មិន (not) |

`&&` និង `||` មានឥរិយាបថ **short-circuit**៖ បើលទ្ធផលច្បាស់ពីផ្នែកខាងឆ្វេងហើយ
ផ្នែកខាងស្ដាំមិនត្រូវគណនាទេ។ នេះសំខាន់ព្រោះវាអាចការពារការគណនាដែលមិនមានសុវត្ថិភាព៖

```cpp
if (index < size && data[index] != 0) {
    // បើ index >= size ផ្នែកខាងស្ដាំមិនត្រូវអាន data[index] ទេ
}
```

## ប្រមាណវិធីដាក់តម្លៃ

```cpp
int x = 10;
x += 5;    // x = x + 5  -> 15
x -= 3;    // 12
x *= 2;    // 24
x /= 4;    // 6
x %= 4;    // 2
```

`++` និង `--` បង្កើន ឬបន្ថយមួយ។ `++x` (prefix) បង្កើនមុនពេលប្រើ ចំណែក `x++`
(postfix) ប្រើតម្លៃចាស់មុន រួចទើបបង្កើន។

## ប្រមាណវិធីផ្សេងទៀត

| ប្រមាណវិធី | អត្ថន័យ |
| --- | --- |
| `&`, `\|`, `^`, `~`, `<<`, `>>` | bitwise (លើ bit) |
| `?:` | ternary — `cond ? a : b` |
| `sizeof` | ទំហំជា byte |
| `,` | ប្រតិបត្តិការតាមលំដាប់ |
| `.` និង `->` | ចូលដល់សមាជិករបស់វត្ថុ |

## លំដាប់ប្រមាណវិធី (precedence)

`*` និង `/` មានលំដាប់ខ្ពស់ជាង `+` និង `-`។ ប្រមាណវិធីប្រៀបធៀបមានលំដាប់ខ្ពស់ជាង
`&&` ដែលខ្ពស់ជាង `||`។ បើមិនប្រាកដ សូមប្រើវង់ក្រចក — វាអានងាយជាង និងជៀសវាង
កំហុស។
