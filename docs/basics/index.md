# C++ មូលដ្ឋាន

ផ្នែកនេះគ្របដណ្ដប់អ្វីៗដែលអ្នកនឹងប្រើរាល់ថ្ងៃ៖ អថេរ ប្រភេទទិន្នន័យ ប្រមាណវិធី
