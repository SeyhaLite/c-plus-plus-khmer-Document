# មតិយោបល់ក្នុងកូដ (Comments)

```{translation-meta} basics/comments
```

មតិយោបល់ (Comment) គឺជាអត្ថបទដែលកម្មវិធីបកប្រែមិនអាន។ វាមានប្រយោជន៍សម្រាប់
ពន្យល់ហេតុផលនៅពីក្រោយកូដ។

## មតិយោបល់បន្ទាត់តែមួយ

```cpp
int count = 0;   // ចំនួនអ្នកប្រើដែលបានចូល
```

អ្វីៗពី `//` ដល់ចុងបន្ទាត់ត្រូវបានមិនអាន។

## មតិយោបល់ប្លុក

```cpp
/*
  មតិយោបល់ប្លុកអាចមានច្រើនបន្ទាត់។
  វាមានប្រយោជន៍សម្រាប់ការពន្យល់វិធីសាស្ត្រស្មុគស្មាញ។
*/
```

មតិយោបល់ប្លុក **មិនអាច** ដាក់បញ្ចូលគ្នា (nested) បានទេ។ បើអ្នកសរសេរសញ្ញាបើក
ប្លុកនៅខាងក្នុង វានឹងបញ្ចប់ប្លុកខាងក្រៅមុនពេលដែលអ្នករំពឹង។

## មតិយោបល់សម្រាប់ឯកសារ

ឧបករណ៍បង្កើតឯកសារដូចជា Doxygen អានមតិយោបល់ដែលចាប់ផ្ដើមដោយ `///` ឬ `/**`៖

```cpp
/// ត្រឡប់ផលសងរវាង a និង b។
int difference(int a, int b) {
    return a - b;
}
```

## មតិយោបល់ជាភាសាខ្មែរ

អ្នកអាចសរសេរមតិយោបល់ជាភាសាខ្មែរបានដោយផ្ទាល់ ដរាបណាឯកសារត្រូវបានរក្សាទុកជា UTF-8។
កម្មវិធីបកប្រែទំនើបទាំងអស់គាំទ្រ UTF-8។

## អ្វីដែលគួរសរសេរ និងអ្វីដែលមិនគួរ

:::{admonition} គោលការណ៍
សរសេរមតិយោបល់ពន្យល់ **ហេតុអ្វី** មិនមែន **អ្វី**។
កូដខ្លួនឯងបង្ហាញរួចហើយថាវាធ្វើអ្វី។
:::

មិនល្អ៖

```cpp
i += 1;   // បន្ថែម 1 ទៅ i
```

ល្អជាង៖

```cpp
i += 1;   // រំលងបន្ទាត់ថ្នាក់ក្បាលរបស់ CSV
```

## ការបិទកូដជាបណ្ដោះអាសន្ន

ការប្រើមតិយោបល់ដើម្បីបិទកូដគឺជាទម្លាប់ដែលគេឃើញញឹកញាប់ ប៉ុន្តែមានហានិភ័យ៖
កូដដែលបិទទុកយូរនឹងក្លាយជាកូដចាស់ដែលមិនដំណើរការ។ បើអ្នកប្រើ Git សូមលុបវាចោល
ហើយទុកប្រវត្តិក្នុង commit វិញ។
