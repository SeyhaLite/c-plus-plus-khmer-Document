```{translation-meta} basics/syntax
```

## រចនាសម្ព័ន្ធកម្មវិធី C++

កម្មវិធី C++ មួយមានផ្នែកសំខាន់ៗដូចខាងក្រោម៖

1. **សេចក្ដីបង្គាប់ព្រៃដំណើរការ (preprocessor directives)** — ចាប់ផ្ដើមដោយ `#`។
   ឧទាហរណ៍ `#include <iostream>`។ វាត្រូវដំណើរការមុនការបកប្រែ។
2. **ការប្រកាស និងការកំណត់ (declarations and definitions)** — បង្កើតអថេរ
   អនុគមន៍ ថ្នាក់ និងវត្ថុ។
3. **អនុគមន៍ `main`** — ចំណុចចាប់ផ្ដើមរបស់កម្មវិធី។
4. **សេចក្តីថ្លែងការណ៍ (statements)** — បញ្ជាដែលបញ្ចប់ដោយ `;`។

## ចំណុចវាក្យសម្ព័ន្ធសំខាន់ៗ

**ករណីអក្សរ (case sensitivity)។** C++ បែងចែកអក្សរធំ និងតូច។
`Area`, `area` និង `AREA` ជាឈ្មោះបីផ្សេងគ្នា។

**សញ្ញាចុងបញ្ចប់ `;`។** សេចក្តីថ្លែងការណ៍នីមួយៗត្រូវបញ្ចប់ដោយ `;`។
ការប្រកាសអនុគមន៍ និងថ្នាក់ក៏ត្រូវការ `;` ដែរ (លើកលែងតែ `main` មិនត្រូវការ
បន្ទាប់ពី `}`)។

**ប្លុក `{ }`។** ប្លុកបង្កើតដែនកំណត់ (scope) ថ្មី។ អថេរដែលបង្កើតក្នុងប្លុក
មិនអាចប្រើនៅខាងក្រៅបានទេ។

**ចន្លោះទំនេរ។** C++ មិនខ្វល់ពីចន្លោះ ឬបន្ទាត់ថ្មីទេ (free-form language)។
អ្នកអាចសរសេរកូដក្នុងបន្ទាត់តែមួយបាន ប៉ុន្តែការរៀបចំឱ្យអានងាយគឺសំខាន់ណាស់។

## ឈ្មោះអ្នកសម្គាល់ (identifiers)

ឈ្មោះអថេរ អនុគមន៍ និងថ្នាក់ត្រូវគោរពច្បាប់ទាំងនេះ៖

- ចាប់ផ្ដើមដោយអក្សរ ឬ `_`។
- អាចមានអក្សរ លេខ និង `_`។
- មិនអាចជាពាក្យគន្លឹះ (`int`, `class`, `return`, ...)។

:::{warning}
ឈ្មោះដែលមាន `__` ពីរដង ឬចាប់ផ្ដើមដោយ `_` និងអក្សរធំ ត្រូវបានបម្រុងទុកសម្រាប់
implementation។ អ្នកមិនត្រូវប្រើវាឡើយ ព្រោះវាអាចប៉ះទង្គិចជាមួយបណ្ណាល័យ
ឬកម្មវិធីបកប្រែ។
:::

## ស្តង់ដារ

ឧទាហរណ៍នេះប្រើ `constexpr` ដែលមានតាំងពី **C++11**។
បើអ្នកបកប្រែដោយ `-std=c++98` វានឹងមិនដំណើរការទេ។
